# TemanHutang

Aplikasi web pribadi untuk mencatat dan mengelola hutang teman secara terstruktur.

## Tech Stack

- React + TypeScript
- Tailwind CSS
- Lucide Icons
- Vite
- Supabase *(disiapkan pada layer layanan untuk integrasi tahap berikutnya)*

## Menjalankan Secara Lokal

```bash
npm install
npm run dev
```

## Build Produksi

```bash
npm run build
```

## Catatan

- Saat ini berjalan dalam mode simulasi lokal (mulai dari 0 data, opsi muat data contoh tersedia di menu Pengaturan).
- Belum terhubung ke Supabase dan tidak menyimpan kredensial di frontend.
